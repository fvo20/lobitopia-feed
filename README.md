# Lobitopia — Live & Episode Feed

A podcast-style RSS feed for the **Lobitopia** kids' channel (Lobita & Robito).

**Feed URL (GitHub Pages):** https://fvo20.github.io/lobitopia-feed/podcast.xml
**Feed URL (raw):** https://raw.githubusercontent.com/fvo20/lobitopia-feed/main/podcast.xml

**Channel:** https://www.youtube.com/@lobitopiatv · TikTok: https://www.tiktok.com/@fvo45

## What's in the feed
- The current/upcoming YouTube **LIVE** loop entry (points to the channel's /live page)
- Full long-form episodes as they premiere

## Updating
Edit `podcast.xml` (newest item first) and commit. The GitHub Pages URL updates automatically.
The live entry's link stays pointed at the channel /live page, which always resolves to the current live stream.
